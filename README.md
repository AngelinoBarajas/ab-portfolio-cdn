# ab-portfolio-cdn

Built files only for barajasdsgn.com, served through jsDelivr:

`https://cdn.jsdelivr.net/gh/AngelinoBarajas/ab-portfolio-cdn@<version>/code/dist/<file>`

Each tag holds `code/dist` and `code/vendor` exactly as built for that release, so every URL is pinned and every
file keeps its integrity hash. The source lives in a private repo; nothing here is edited by hand.
